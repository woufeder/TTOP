# First Worldbuilding Note

The first phase of this archive is not about filling every page with lore. It is about building a content structure that can keep growing.

## Why start with a static content flow

- Maps, timelines, characters, and articles can all grow from JSON or Markdown.
- No backend or database is required to deploy the site on GitHub Pages.
- Adding a new article does not require editing Vue components. You only add a Markdown file.

## Possible next steps

1. Locale-specific article folders such as articles/en and articles/it.
2. Content shortcodes that turn characters, places, and factions into inline cards.
3. A static search index with Fuse.js on the client.

> The current text is placeholder content. The real goal of phase one is the layout, information architecture, and content workflow.
