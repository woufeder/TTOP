# Prima Nota di Worldbuilding

La prima fase di questo archivio non serve a riempire ogni pagina di lore. Serve a costruire una struttura di contenuti che possa crescere nel tempo.

## Perché partire da un flusso statico di contenuti

- Mappe, timeline, personaggi e articoli possono crescere da JSON o Markdown.
- Non serve un backend o un database per pubblicare il sito su GitHub Pages.
- Per aggiungere un nuovo articolo non serve toccare i componenti Vue: basta aggiungere un file Markdown.

## Possibili sviluppi successivi

1. Cartelle articolo separate per lingua, come articles/en e articles/it.
2. Shortcode che trasformano personaggi, luoghi e fazioni in schede inline.
3. Un indice di ricerca statico con Fuse.js lato client.

> Il testo attuale è ancora placeholder. Nella prima fase contano soprattutto layout, architettura dell informazione e flusso dei contenuti.
